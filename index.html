Concepts clés

Partie 1 - Découvrez le web et ses origines

Web

Le Web est un service d'Internet qui permet de consulter des pages reliées entre elles par des liens hypertextes. Son nom vient de "World Wide Web" c'est-à-dire "toile mondiale" en français. Il a été créé par Tim Berners-Lee et rendu public en 1991.

Internet

Internet est un réseau mondial qui permet aux ordinateurs et aux appareils de communiquer entre eux. Il a été inventé vers 1969 sous le nom d'ARPAnet, avant de prendre le nom d'Internet par la suite. Grâce à Internet, on peut utiliser plusieurs service dont le Web, les e-mails et bien d'autres.

Cloud

Le Cloud signifie "nuage" et c'est un service fourni via Internet. Il nous permet de stocker et conserver nos données pour éviter de les garder uniquement sur notre ordinateur. On peut accéder au Cloud de partout avec une connexion Internet et lorsqu'on a besoin de plus d'espace pour stocker nos données, il peut être agrandi.

W3C

Le W3C, ou World Wide Web Consortium, est une organisation internationale fondée en 1994 par Tim Berners-Lee. Il développe des standards et des règles techniques afin de favoriser un Web accessible et compatible avec les différents navigateurs et appareils. Il publie aussi des recommandations pour faciliter l’accès au Web aux personnes en situation de handicap et met à disposition des outils gratuits permettant aux développeurs de vérifier la conformité de leur code.

Partie 2 - Distinguez les langages du Web

Langages client

Les langages clients fournissent les informations de base nécessaires à l'affichage et à la construction de la page Web. Ils sont lus par le navigateur Web qui se trouve sur l'ordinateur de l'utilisateur, c'est-à-dire la personne qui consulte une page Web.

Navigateurs

Il existe plusieurs navigateurs Web, comme Google Chrome ou Firefox. Peut importe le navigateur utilisé, ils ont tous le même rôle : traduire les langages client en pages Web compréhensibles pour tout le monde.

Langages serveur

Les langages serveur sont utilisés par les serveurs. Ils permettent de décrire comment le site doit se comporter.

Frameworks

Les frameworks sont comparables à des boîtes à outils qui permettent de structurer l’ensemble du code d’un projet. Ils fournissent des dossiers et des fichiers bien structurés ainsi que des modèles standardisés afin de faciliter et d’accélérer le développement du projet. Ils doivent être téléchargés, inclus dans le projet puis utilisés dans l’IDE.

Bases de données

La base de données est un logiciel dédié à stocker des données. Les sites Web l’utilisent pour stocker, par exemple, la liste de leurs utilisateurs. Pour communiquer avec elle, on utilise le langage SQL.

Site responsive

Un site responsive est un site qui s’adapte automatiquement à la taille de l’écran de l’utilisateur. Il est donc compatible aussi bien avec les ordinateurs qu’avec les tablettes et les smartphones.

Application mobile

Une application mobile est conçue uniquement pour les tablettes ou les smartphones. Elle est plus longue à réaliser et se développe avec des langages mobiles spécifiques à Android et iOS. Elle est plus adaptée à la création d’un jeu, car elle offre une meilleure expérience à l’utilisateur.

Partie 3 - Découvrez le fonctionnement du réseau

Serveurs

Les serveurs sont des machines qui hébergent les sites Web et les distribuent aux utilisateurs qui souhaitent les consulter. Ils exécutent le code en langage serveur pour générer la page, puis envoient au navigateur les éléments en langages client. Ils peuvent également communiquer avec une base de données à l’aide du langage SQL.

Adresse IP

Chaque ordinateur et chaque serveur connecté à Internet possède une adresse IP. Elle permet de retrouver un ordinateur ou un serveur sur le réseau, un peu comme un numéro de téléphone. Une adresse IP est composée d’une suite de nombres.

Nom d’hôte et DNS

Les noms d’hôte nous permettent d’accéder à un serveur sans avoir besoin de connaître son adresse IP. Lorsque l’on tape un nom d’hôte, comme « google.com », le DNS intervient. Il agit comme un annuaire : il traduit le nom d’hôte en adresse IP, ce qui permet au navigateur d’accéder au serveur et d’afficher la page Web.

Protocoles

Les protocoles sont des langages de communication que les machines utilisent pour communiquer entre elles. Il existe des protocoles de bas niveau, comme TCP, et des protocoles de haut niveau, comme HTTP ou HTTPS. Les protocoles de haut niveau reposent généralement sur les protocoles de bas niveau.

Partie 4 - Identifiez les métiers du web

Développeurs

Les développeurs sont des personnes qui conçoivent, testent, documentent et maintiennent des sites Web, des logiciels ou des applications. Ils passent aussi beaucoup de temps à tester leur code, à résoudre des problèmes et à améliorer leurs méthodes de développement. Ils peuvent utiliser l’IA pour comprendre un code, le simplifier ou repérer des erreurs.

Product Managers et chefs de projets

Le Product Manager réalise des études de marché, analyse les données des utilisateurs et définit la stratégie ainsi que l’évolution du produit à long terme. Le chef de projet organise le travail des différentes équipes et suit l’avancement du projet. Il veille à ce que le produit final respecte les objectifs et les besoins définis.

Designers

Les designers doivent s’assurer que le site ou l’application répond aux attentes et aux besoins des utilisateurs. Ils cherchent à rendre la navigation simple, fluide et intuitive. Ils travaillent aussi sur l’apparence et l’accessibilité de l’interface.

Testeurs

Les testeurs sont chargés de concevoir, d’exécuter et d’automatiser des tests afin de repérer les bugs et les problèmes de performance avant la mise en ligne du produit. Leur travail consiste à garantir la qualité et le bon fonctionnement du site ou de l’application. Ils signalent les anomalies aux développeurs afin qu’elles soient corrigées.

Techniciens informatique

Le technicien informatique s’assure du bon fonctionnement du matériel informatique, comme les ordinateurs et les périphériques, ainsi que des systèmes d’exploitation, comme Windows. Il veille aussi à ce que tous les postes de travail aient accès au réseau de l’entreprise (Wi-Fi, câbles et accès à Internet), aux applications et aux services nécessaires. Il conseille les utilisateurs, les aide à devenir autonomes et résout leurs problèmes informatiques.

Langages de développement web

HTML

Front-End

Squelette du site Web. Il définit la structure de base du contenu, comme les titres, les paragraphes, les images, etc.

CSS

Front-End

Il définit le style d'un site Web, comme les couleurs, les polices, les tailles et la mise en page. Il permet de rendre un site plus agréable, lisisble et personnalisé.

JavaScript

Front-End

Il permet de d’ajouter des interactions sur un site Web, comme des menus déroulants ou l’affichage de messages lors de la validation d’un formulaire. Il rend le site plus interactif et dynamique.

JavaScript

Back-End

Le JavaScript back-end est exécuté sur un serveur grâce à un environnement comme Node.js. Il permet de gérer l’authentification des utilisateurs, les échanges avec la base de données et l’envoi des informations au navigateur.

PHP

Back-End

PHP est un langage serveur qui permet de définir le comportement d’un site Web. Il sert à générer des pages Web avant de les envoyer au navigateur. Il peut aussi communiquer avec une base de données pour récupérer ou enregistrer des informations.

Java

Back-End

Java est un langage serveur qui permet de définir le comportement d’un site Web. Il sert à traiter les demandes des utilisateurs et à générer des pages Web. Il peut aussi communiquer avec une base de données et être utilisé avec des frameworks comme Java EE.

Python

Back-End

Python est un langage serveur qui permet de définir le comportement d’un site Web. Il peut traiter les demandes des utilisateurs, générer des pages Web et communiquer avec une base de données. Il peut être utilisé avec un framework comme Django.

C#

Back-End

C# est un langage serveur qui permet de définir le comportement d’un site Web. Il peut générer des pages Web et communiquer avec une base de données. Il peut être utilisé avec le framework ASP.NET.

SQL

Bases de données

SQL est le langage utilisé pour effectuer des requêtes auprès d’une base de données. Il permet de récupérer, d’ajouter ou d'enregistrer des informations. Généralement, c’est le serveur qui communique avec la base de données à l’aide du langage SQL.

Boîte à outils du développeur

  • IDE comme VS Code : sont les environnements de travail des développeurs. Ils permettent d’écrire du code, de retrouver facilement l’arborescence des fichiers et de bénéficier de la complétion automatique. Ils facilitent aussi la lecture du code grâce à la mise en couleur de celui-ci.
  • Github : est un outil qui permet de stocker et de partager le code d'un projet dans un dépôt appelé repository. GitHub Pages permet également d’afficher un site Web en ligne.
  • Librairies / bibliothèques : sont des morceaux de code écrits par d’autres développeurs et réutilisables pour gagner du temps. Elles peuvent être utilisées pour répondre à des besoins courants ou spécifiques.
  • Frameworks : Un framework est un ensemble d’outils, de composants et de règles qui fournit une structure pour organiser le code d’un projet. Il permet aux développeurs de gagner du temps et de faciliter la création de sites Web complexes. Par exemple, Symfony est associé à PHP, Django à Python et Java EE à Java.
